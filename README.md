# Dr. De SouzAI Thumbnail Architect

Professional extension for Dr. De Souza to architect viral, high-fidelity thumbnails with ease.

## Installation Instructions

Follow these steps to set up the extension in your Google Chrome browser:

1. **Download the Repository:**
   - Click the green **Code** button on the GitHub page and select **Download ZIP**.
   - Extract the downloaded ZIP file to a convenient folder on your computer.

2. **Enable Developer Mode:**
   - Open Google Chrome and navigate to `chrome://extensions/` by typing it into the address bar.
   - In the top right corner, toggle the **Developer mode** switch to **ON**.

3. **Load the Extension:**
   - Click the **Load unpacked** button that appears in the top left.
   - Navigate to and select the folder where you extracted the extension files (the folder containing `manifest.json`).

## How to Use

1. Open the Chrome Side Panel (click the side panel icon near the top right of your browser).
2. Select **Dr. De SouzAI Architect** from the dropdown menu.
3. Click the **Generate Viral Thumbnail** button.
4. The status bar will show the real-time "architecting" progress.
5. Once complete, a high-fidelity placeholder "image" will appear in the preview area.
