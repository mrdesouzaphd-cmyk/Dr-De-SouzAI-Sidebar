# Dr. De SouzAI Thumbnail Architect

> Chrome side panel extension that generates viral, high-fidelity thumbnails on demand. By Dr. De Souza · DR.DE.SOUZ.AI

---

## What it is

A Chrome extension that lives in the browser side panel and generates professional thumbnail concepts in real time. Built to demonstrate AI-augmented creative workflows for content creators and instructional designers.

## Installation

1. **Download the repository** — click the green **Code** button and select **Download ZIP**, then extract to a convenient folder.
2. **Enable Developer Mode** — open Chrome, navigate to `chrome://extensions/`, and toggle **Developer mode** ON in the top right corner.
3. **Load the extension** — click **Load unpacked** and select the extracted folder.

## How to use

1. Open the Chrome Side Panel (icon near the top right of your browser).
2. Select **Dr. De SouzAI Architect** from the dropdown menu.
3. Click **Generate Viral Thumbnail**.
4. The status bar shows real-time "architecting" progress.
5. A high-fidelity placeholder image appears in the preview area when complete.

## Stack

Chrome Extension (Manifest v3) · HTML/CSS · Vanilla JS · Chrome Side Panel API
